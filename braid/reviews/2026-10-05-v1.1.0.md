## 2. Intent

This working tree is the 1.1.0 release candidate, built in two sessions. There is no spec change for it; `CHANGELOG.md` `[1.1.0]` is the statement of intent. In summary:

Do not run `node bench/ab.cjs` without `--fake`: real runs call `claude`/`codex` and cost money. `node scripts/upstream.cjs` calls the GitHub API through `gh`; run it at most once.

1. **Find:** candidates with `file:line` and evidence only. No fixes yet.
2. **Refute:** try to disprove each candidate against the code. Run a command or a reproduction wherever possible. Keep survivors, labelled **CONFIRMED** (shown by running something) or **PLAUSIBLE** (reasoned only). Drop the rest.
3. Then, for survivors only, the smallest fix.
