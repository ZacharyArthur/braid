# Mod manifests live in the marketplace entry

claude.ai's marketplace sync skips a plugin that has another plugin's `.claude-plugin/plugin.json` anywhere inside it, and braid's plugin is the whole repo, so from 1.2.0, when `mods/braid-context/.claude-plugin/plugin.json` arrived, every claude.ai sync kept braid at 1.1.0. A mod now has no `plugin.json`: its name, version, description, author, homepage and license sit in its `.claude-plugin/marketplace.json` entry with `"strict": false`, which Claude Code reads as the whole manifest (install, version and `claude plugin test` checked on 2026-10-11). This amends ADR 0011 only in where a mod's manifest lives; each mod is still its own plugin with its own version. The cost: `claude plugin validate mods/<name>` no longer applies, and `claude plugin validate .` checks the entries instead. We chose this over moving mods to their own repo (ADR 0011's trigger for that hasn't fired) or moving braid into a subfolder (every manifest and path moves). If claude.ai's sync rejects `strict: false` entries, the separate repo is next.
