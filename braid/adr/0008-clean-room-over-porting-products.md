# Clean-room small skills instead of porting large products

`design`, `map`, `wayfind`, `handoff` and `xreview` are written from scratch at ≤ ~2k tokens, inspired by impeccable, taste-skill, ui-ux-pro-max, graphify and mattpocock's wayfinder. Those are full products (CLIs, detectors, 300 KB references, issue-tracker integrations) and two are Apache-2.0; porting slices would mean owning code shaped for someone else's runtime. The README lists them as companions to install when the full thing is needed.
