# Route: v1

## Destination
braid v1.0.0 public at ZacharyArthur/braid, installable in Claude Code, Codex and ZCode, with every v1 design decision made. Remaining build work is the `ship-v1` change.

## Decided
- Pillars: YAGNI > KISS > DRY, rule of three, knowledge single-sourced ([ADR 0001](../adr/0001-three-strands-precedence.md))
- Corner-cut marker: `braid(yagni|kiss|dry): <ceiling>, <upgrade path>`; zero GitHub hits, grep-safe
- Verification: no "done/fixed/passing" without running the check this turn (from superpowers, in core)
- Packaging: one plugin, three manifests, one hooks file, user-only expressed per harness ([ADR 0002](../adr/0002-one-plugin-three-harnesses.md))
- Name: braid; repo `ZacharyArthur/braid`; MIT; semver + tags + hand-written CHANGELOG; v1.0.0 at launch, `braid/` layout stable from day one
- Upstream: vendor verbatim, pin SHAs in UPSTREAM.md, separate verbatim and edit commits ([ADR 0003](../adr/0003-vendor-verbatim-with-pins.md))
- Credit: upstream LICENSE per vendored folder, `license`/`metadata.source` frontmatter, README credits in three tiers; no attribution in skill bodies
- Hook: one stdlib `.cjs` script, Node ≥ 18, silent degrade ([ADR 0006](../adr/0006-node-cjs-stdlib-hook.md))
- Always-on: inject core + pointers, ~2-2.5k token cap ([ADR 0007](../adr/0007-always-on-token-budget.md))
- Levels lite/full/ultra via a slim per-session tracker; drift reminder off by default; no statusline
- Core skill: broad description, small body (examples, hardware) loaded on demand
- Skills from ponytail: review, audit, debt kept and widened to three pillars; gain and help dropped
- Grilling: upstream rounds version vendored, plus grill-me and grill-with-docs aliases
- domain-modeling vendored with paths moved to `braid/adr/` and `braid/GLOSSARY.md`
- Spec workflow: CLI-free, in `braid/` ([ADR 0004](../adr/0004-cli-free-spec-in-braid-folder.md)); one skill, verbs propose/apply/archive/discover in separate files
- discover: never edits code; code-vs-intent mismatches become proposal-only `fix-*` changes
- Compaction survival: state on disk + SessionStart pointers, no enforcement hooks ([ADR 0005](../adr/0005-state-on-disk-not-enforcement.md))
- adhd: vendored verbatim, off by default, tracker re-injects it after compaction
- humanizer, security-audit, systematic-debugging: vendored, user-only
- superpowers: only systematic-debugging and the verification rule; TDD rejected for ponytail's one-check rule
- Clean-room skills instead of ported products ([ADR 0008](../adr/0008-clean-room-over-porting-products.md)): design, map, wayfind, handoff, xreview
- map: `braid/map.md` ≤150 lines with a Mermaid module diagram; patched by `spec archive`
- wayfind: local markdown route files in `braid/routes/`; tracker sync deferred to v1.1
- handoff: `braid/HANDOFF.md`, 80-120 lines, links never copies
- xreview: prompt for another model; adversarial or `--open`; find → refute → fix survivors
- Testing: `scripts/check.cjs` in CI on Windows and Ubuntu, TESTING.md manual checklist, manual A/B vs ponytail
- standards: `/braid:standards` writes the root AGENTS.md (commands, before-done checks, conventions, git incl. agent permissions) + `CLAUDE.md` = `@AGENTS.md`; detect → recommend gaps from `stacks.md` → confirm in rounds → run every command; review mode reports gaps/drift/broken; documentation only; ~100 lines (~150 monorepo) ([ADR 0009](../adr/0009-agents-md-owns-commands.md))
- Benchmark: `bench/ab.cjs` runs outside the home folder; rule of three tightened (third exact copy, value-only differences count, extract instead of writing); rung 2 gained a cheap search; reuse without a map still 0/3 (v1.1: test with `braid/map.md`)
- standards v2: default sections Project (priorities), Stack, Commands, Before saying done, Conventions, Git (+ never mention AI tools, confirm commit/PR text), Don't; optional Dev environment, Invariants, Workflow, Security, Reference; template in `template.md`
- Spec frameworks: AGENTS.md declares, else detect; OpenSpec first-class, others asked once and followed; hook follows `openspec/changes` ([ADR 0010](../adr/0010-follow-the-projects-spec-framework.md))
- Reuse on Claude: a dictated algorithm is implemented inline whatever the rules or map pointer say (12 runs); open prompts reuse in every arm; Codex reuses either way. Stop tuning; keep all three bench variants
- Coexistence: don't run with ponytail; user uninstalls ponytail and personal grilling after v1 is verified
